# Adaptive Polices

自适应策略设计：

- 基于启发式算法的自适应策略：根据规则来调整策略，以达到最优策略。
    - 根据输入的序列长度，简单地选择不同的策略。
- 基于模型的自适应策略：可以根据预训练好的模型来选择策略，以达到最优策略。
    - 使用监督学习来训练模型，根据输入的序列长度和得到的时间，内存开销作为数据来训练模型。
- 基于强化学习的自适应策略：基于强化学习的自适应策略是指使用强化学习算法来训练策略，以达到最优策略。
    - 利用监督学习所得来的模型作为基模型，在不同集群的环境中动态进行训练，以达到该集群下的最优策略。
    - RL的Agent的输入应该和基于模型的自适应策略的输入相同。
